# Gaoding Toolkit

面向稿定设计页的油猴脚本，用于在在线页面或本地保存页面中直接提取并保存预览图。

## 包含文件

- `gaoding-toolkit.user.js`

## 功能简介

- 自动拦截 `risk_materials` 相关请求
- 优先触发并截获页面原生下载产物
- 下载优先级：
  - `PDF > PSD > PNG > JPG/JPEG > WEBP > AVIF`
- 若未截获到原生下载结果：
  - 回退到当前可见画布
  - 仍失败时再回退到 `window.__SSR_TEMPLATE.preview.url`
- 页面右下角提供一个低调的“保存图片”按钮
- 右键按钮可复制原图地址
- 支持在线设计页与 `file://` 本地保存页面

## 食用方式

### 1. 安装脚本

使用 Tampermonkey 安装：

- `gaoding-toolkit.user.js`

### 2. 在线页面使用

打开稿定设计页后：

- 页面右下角会出现“保存图片”按钮
- 左键点击：保存当前可获取到的最佳结果
- 右键点击：复制原图地址

### 3. 本地页面使用

如果是浏览器保存下来的稿定页面：

- 需要在 Tampermonkey 中为该脚本开启 `file://` 页面访问权限
- 打开本地 html 后，仍可使用右下角按钮尝试保存预览图

## 适用场景

- 在线设计页快速保存预览图
- 本地保存页提取原始预览图地址
- 不想手动抓请求时的轻量化辅助保存

## 注意事项

- 不同页面结构、渲染状态、下载链路可能不同，最终保存结果以页面当时可获取的数据为准
- 若页面本身没有可用预览图或导出结果，按钮会显示无法保存状态
- 本脚本更适合作为个人辅助工具使用
